# Manifest

Trip packing lists. One page, works offline, installs to a phone home screen.

Live: https://laemaison.github.io/manifest/

## Editing

**Edit `src/app.html`, not `index.html`.** `index.html` is generated and will be
overwritten.

```sh
cd build
npm install      # first time only
node build.js    # regenerates ../index.html
```

The build inlines React and ReactDOM and pre-compiles the JSX with Babel's
classic runtime, so the published page fetches no scripts at runtime. That is
what makes it work on a plane.

To regenerate the icons after a colour change: `node build/gen-icons.js`.

## Files

| Path | What it is |
|---|---|
| `src/app.html` | The source you edit |
| `index.html` | Generated, self-contained, ~186KB |
| `sw.js` | Service worker; precaches the shell, caches fonts on first load |
| `app.webmanifest` | PWA metadata for install |
| `icon-192.png`, `icon-512.png` | Generated by `build/gen-icons.js` |

## Gotchas

- Trips live in `localStorage`, which is per-origin **and per-device**. Moving
  to a new domain, or to your phone, needs *Save a backup* then *Restore a
  backup*. There is no sync.
- Bump `VERSION` in `sw.js` when shipping a change, or returning visitors keep
  the cached old shell.
